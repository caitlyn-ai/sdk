# caitlyn-sdk-core

The hand-written runtime behind [`caitlyn-sdk`](../README.md), the Caitlyn SDK for Rust: the Caitlyn wire protocol,
sign-in modes, retries, server-sent event streams with resume, pagination, presigned uploads, `@since` checks and
`tracing` spans. Use `caitlyn-sdk`; this crate is what it is built on. Apache-2.0.
