# caitlyn-core

The runtime behind [`caitlyn`](https://pypi.org/project/caitlyn/), the Python SDK for the Caitlyn API: sign-in,
retries, errors, streamed answers, pagination, uploads and OpenTelemetry tracing.

Install `caitlyn`, not this package: `pip install caitlyn` brings the matching version of `caitlyn-core` with it.

The documentation is at https://build.caitlyn.ai/. The source is at https://github.com/caitlyn-ai/sdk. Apache-2.0.
