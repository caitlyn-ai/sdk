- **The release v3 arrived in:** the reference names Caitlyn 5.149.0 as the release that added each v3 operation,
  where it said 5.144.0. See [The SDK reference](/sdk/).
- **An older server is refused before sending:** against a server older than 5.149.0, a call raises
  `NotSupportedByServer` without sending it, where it was sent and refused by the server. See
  [Versions and older servers](/getting-started/#versions-and-older-servers).
