- **Every operation is available:** the reference no longer says v3 operations are "not available yet". Each one
  names the release that added it. See [The SDK reference](/sdk/).
- **Retry-safe publishing and resets:** publishing an agent's draft and resetting it take an idempotency key, which
  the SDKs send for you, so a call that times out is retried without publishing twice. See [Retries](/retries/).
- **Guest-safe access:** setting a knowledge base's access is refused with `RBAC_NOT_GUEST_SAFE` when a grant isn't
  safe for a role that guests use. See [RBAC_NOT_GUEST_SAFE](/errors/RBAC_NOT_GUEST_SAFE/).
